China Supplier Finder

Discover Chinese manufacturer, wholesaler and sourcing-agent leads for any product

Direct web crawler — v3.0

The crawler is written in Python and runs using Streamlit. GitHub Pages cannot execute Python or crawl third-party websites. This page is the project's public home, not a live search dashboard.

View crawler source on GitHub

Run the crawler

  1. Install Python 3.11 or newer.
  2. Clone or download the GitHub repository.
  3. Run pip install -r requirements.txt.
  4. Run streamlit run app.py.
  5. Enter a product and permitted starting URLs to collect public supplier leads.

To run online, deploy the Python app on Streamlit Community Cloud from this GitHub repository.

Limitations

Results are unverified public-page leads. The crawler needs seed URLs and respects robots.txt. It does not discover every supplier in China or bypass website restrictions.
